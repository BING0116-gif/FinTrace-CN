## 1. 目标

产业链传导分析。**修正 v2 数学设计**：`Σ(路径边权) × price_change` 的线性加总对多级传导是错的——多级传导涉及链式乘积、非线性与节点模型。

## 2. 金融逻辑（重设）

必须区分四个量：`cost_share`（成本占比）、`pass_through_ratio`（传导率，价格变动沿链传递的比例）、`exposure`（企业对该因素的敞口）、`elasticity`（弹性）。

多级传导 = 链式乘积：上游价格变动 ΔP_u 经各级 pass_through_ratio 连乘传导，再按各节点 cost_share 折算到该节点成本与利润率影响——**不是简单求和**。非线性与节点模型（供需、库存缓冲）无可靠数据与定义前**不做**。

## 3. 入场条件

- 四个量的数据来源与定义全部落地（sourced 或 assumption 登记表）
- 边界声明机制（线性假设/静态占比的失效条件）就绪
- 两条以上做不到 → 本卡不开发，在答辩材料中如实说明"评估后未实现及原因"（如 v2 计划所示范的：不用看起来数学化但没有金融意义的公式）

## 4. 其余字段

- **输入/输出**：静态链图谱（JSON）+ 冲击参数 → 节点影响 + 假设登记 + 边界声明
- **Edge Cases**：环检测；缺 pass_through_ratio 的边 → 阻断该路径不估
- **Unit Tests**：链式乘积手工算例（两级/三级）；四量混淆的负例（求和路径拒绝）
- **Demo Method**（决赛）：冲击→传导路径可视化 + 假设与边界展示
- **验收标准**：链式乘积正确；四量分离有测试；边界声明非空
